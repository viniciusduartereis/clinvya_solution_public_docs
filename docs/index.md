✨ **Clinvya** transforma consultas em documentação clínica automaticamente usando IA — reduzindo significativamente a burocracia clínica, podendo chegar a até 1h/dia de trabalho manual por profissional.

**🔍 Palavras-chave: gestão clínica SaaS, IA em saúde, prontuário digital, agendamento médico, controle financeiro clínico.**

---

### 🤖 IA como Core do Produto

A Clinvya não usa IA como feature — a IA é parte central do fluxo clínico.

- 🎙️ Conversa → Transcrição automática
- 🧩 Transcrição → Estrutura clínica (anamnese/evolução)
- 📋 Estrutura → Prontuário pronto para uso

✅ Resultado: menos digitação, mais tempo com o paciente.

---

## 🩺 O Problema

Profissionais de saúde ainda gastam grande parte do tempo com burocracia:
- 📝 Preenchimento manual de prontuários
- 📚 Registro de evolução clínica
- 🗂️ Organização de informações dispersas

Isso reduz o tempo disponível para o paciente e impacta a qualidade do atendimento.

🚀 A Clinvya nasce para resolver exatamente esse problema.

---

## ⚙️ Como Funciona na Prática

1. 👨‍⚕️ Profissional inicia gravação da consulta  
2. ☁️ Áudio é armazenado e enviado para processamento  
3. 🤖 IA realiza transcrição automática  
4. 🧠 Sistema estrutura os dados em formato clínico  
5. 🗄️ Resultado é salvo no prontuário do paciente  

Tudo isso acontece de forma assíncrona e transparente para o usuário.

## 🎯 Filosofia do Projeto

A Clinvya foi construída com base em três pilares:

- 🤖 IA como core, não como acessório  
- 🧱 Arquitetura escalável desde o início  
- ⚡ Velocidade de execução com qualidade (SDD + IA)  

🎯 O objetivo é provar que é possível construir produtos robustos e inteligentes em ciclos curtos usando engenharia moderna.

🧠 Mais do que um sistema de gestão, a Clinvya é um experimento prático de como IA e engenharia moderna podem redefinir produtos SaaS.

## 💡 O que é

- 🏥 Sistema SaaS para clínicas de saúde  
- 👥 Gestão de pacientes, agendas, profissionais e transações  
- 🔐 Estrutura preparada para autenticação corporativa e controle de acesso

## 🧰 Funcionalidades Principais

- 🗓️ **Agenda Inteligente**: Agendamentos recorrentes, confirmações, e remarcações em um fluxo único acompanhando com a visão da taxa de ocupação.  
- 💰 **Controle Financeiro**: Lançamentos, pagamentos, histórico e visão de performance financeira em um só painel  
- 📁 **Prontuário Digital**: Histórico completo do paciente com registros clínicos organizados  
- 🤖 **IA Integrada**: A IA integra gravação, transcrição, resumo e auxilia na escrita da anamnese e da evolução clínica  
- 🔔 **Lembretes Automáticos**: Reduza faltas com WhatsApp (Meta), SMS (Twilio) e e-mail (Resend)  
- 🧬 **Painel 360 do Paciente**: Visão completa integrada (evolução, consultas, financeiro) para engajamento holístico  
- 📊 **Questionários Científicos**: Acompanhamento de scores com questionários validados cientificamente, respondidos diretamente pelo paciente

## 🧱 Arquitetura e Tecnologias

- 🧠 **Backend**: .NET 10 com ASP.NET Core minimal APIs e arquitetura por features para escalabilidade e manutenção  
- 🌐 **Frontend**: Next.js moderno para experiência web responsiva e interativa  
- 🔐 **Autenticação**: Keycloak com token refresh automático e gerenciamento granular de roles  
- 🐳 **Containerização**: Docker e Docker Compose para ambientes consistentes  
- ⚙️ **CI/CD**: GitHub Actions para automação de pipelines de build e deploy  

---

## 🧪 Engenharia de Software

- 📄 **Spec-Driven Development (SDD)**: cada feature nasce com especificação clara, permitindo uso de IA (ex: Codex) para acelerar implementação mantendo qualidade  
- 🧭 **Governança de Contexto**: Sistema de agentes e skills internos para controle de qualidade e consistência  
- ☁️ **Separação de Responsabilidades**: Arquitetura clara entre API, cliente e autenticação  
- 🎧 **Pipeline de Transcrição**: Processamento automatizado de áudio com integração de IA  

---

## 🏗️ Decisões de Arquitetura

- 🧱 Arquitetura orientada a eventos para desacoplar processamento de IA do fluxo clínico  
- 📬 Uso de mensageria (Service Bus) para garantir resiliência e escalabilidade  
- 🔐 Separação clara entre autenticação (Keycloak) e domínio da aplicação  
- 🐳 Deploy em containers para portabilidade e controle de custo (MVP-friendly)  

---

## ☁️ Cloud e Infraestrutura

- 📦 **Azure Blob Storage**: Armazenamento seguro de arquivos de áudio e transcrições  
- 📬 **Azure Service Bus**: Mensageria assíncrona para processamento de transcrições e notificações  
- 🤖 **Azure AI (Speech + OpenAI)**: Serviços de IA para transcrição automática, resumos inteligentes e modelos de linguagem (ex: GPT via Azure OpenAI)  
- 🧱 **Azure Container Apps**: Deploys para backend e consumer, com escalabilidade automática  
- 🔑 **Azure Key Vault**: Gerenciamento seguro de secrets e certificados (preparado para integração)  
- 🌐 **Cloudflare**: Gerenciamento de DNS, domínio e proteção de segurança para aplicações web  
- ✉️ **Resend**: Serviço de e-mail para notificações e lembretes automatizados  
- 📲 **Twilio**: API de SMS para comunicações seguras e lembretes  
- 💬 **Meta (WhatsApp Business)**: Integração para mensagens via WhatsApp, incluindo lembretes e engajamento  

---

## 🔁 CI/CD e Qualidade

- 🚀 **Pipelines Automatizadas**: GitHub Actions para backend, frontend e autenticação, com deploys para Azure  
- ✅ **Cobertura de Testes**: Testes unitários e integração abrangentes para backend (.NET) e frontend (Vitest)  
- 🧪 **Testes**: Suíte completa de testes automatizados, com foco em qualidade e confiabilidade  
- 📘 **Governança Técnica**: Playbooks claros para desenvolvimento, handoff e validação de features

**Visão Geral da Arquitetura:**
- **Frontend**: Next.js hospedado na Azure, interface responsiva para profissionais e pacientes
- **Backend**: .NET 10 API minimalista hospedada no Azure Container Apps, arquitetura por features
- **Autenticação**: Keycloak para gestão de usuários e roles, com refresh token
- **Banco de Dados**: PostgreSQL para dados clínicos e transacionais
- **Cloud Services**: Azure Blob para armazenamento de áudio, Service Bus para mensageria, AI Services / Foundry para transcrição
- **Consumer**: Serviço .NET para processamento assíncrono de transcrições
- **CI/CD**: GitHub Actions automatizando builds, testes e deploys
